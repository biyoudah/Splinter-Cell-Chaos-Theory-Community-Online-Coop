SPLINTER CELL: CHAOS THEORY — COMMUNITY ONLINE CO-OP
Work in progress.

1. Put the launcher beside the game's System folder.
2. For Steam lobbies, provide the Steam-supplied steam_api.dll and start Steam. Direct UDP does not require Steam.
3. Host a public Steam game or a direct UDP room on port 7790.
4. The guest joins the public lobby or enters the room code/IP.
5. In the game, choose COOP -> ONLINE -> CREATE GAME or JOIN GAME.
6. Keep the launcher open while playing.

Cutscene synchronization is not implemented. The launcher will not open a separate video player. Game-build compatibility and live network, voice, and window-mode behavior still need testing. See README.md for build and test status.
