SPLINTER CELL: CHAOS THEORY — COMMUNITY ONLINE CO-OP
Work in progress. Test build v1.0.0-rc3.

The launcher relays the game's co-op discovery and gameplay traffic between two PCs. Choose Steam networking for a public lobby or direct UDP for a private room (port 7790).

1. Put the launcher next to the game's System folder.
2. For Steam, start Steam and provide a compatible steam_api.dll beside the launcher. Direct UDP does not require Steam.
3. Start the launcher. Host a public Steam game or host/join a direct room.
4. In the game, choose COOP -> ONLINE -> CREATE GAME or JOIN GAME.
5. Keep the launcher open while playing.

Cutscene synchronization is not implemented. The launcher does not open a separate video player. Network recovery, voice, display modes, and compatibility with every game build still need testing. See README.md for full details.
